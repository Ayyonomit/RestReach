🚀 Deployment guide
Option 1 — Vercel (recommended, 100% free):
1. Push this file to a GitHub repo
2. Go to vercel.com → Import project → Select your repo
3. Deploy — you get a free yourapp.vercel.app URL instantly

Option 2 — Netlify Drop (no account needed):
1. Go to app.netlify.com/drop
2. Drag & drop the folder with this index.html
3. You get a live URL in 30 seconds

Option 3 — GitHub Pages:
1. Create a repo, upload index.html
2. Settings → Pages → Source: main branch
3. Live at yourusername.github.io/repo-name
